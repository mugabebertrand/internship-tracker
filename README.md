# Internship Tracker (Team Project – UTA)

A Java console application developed as part of a **team-based Object-Oriented Programming (OOP) course project**
at the **University of Texas at Arlington (UTA)**.

The application helps students explore and track internship pathways using a menu-driven
console interface and object-oriented design principles.
